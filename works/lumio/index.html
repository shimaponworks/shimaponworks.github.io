制作の解説｜LP・販促物一式・美容サロン

美容サロン「Lumio」のLP・チラシ・バナー・SNS画像

「乾かすだけで、朝がひとつ軽くなる。」というひとつの言葉で、
LPから、チラシ・リッチメニュー・予約サイト用の画像・バナー・Instagramまでまとめて制作しました。

業種
美容室（髪質改善トリートメント）
制作物
LP、オープン告知のチラシ（A4）、LINEのリッチメニュー、予約サイト用の画像4枚、Webバナー3案、Instagram投稿3枚
担当範囲
コンセプト・構成・文章・デザイン・コーディング・写真選び・印刷用データ
使ったもの
HTML / CSS / JavaScript（チラシや画像もHTML/CSSで組んで書き出し）

※練習として制作した、架空のサロンのサンプルです。店名・住所・電話番号・URLはすべて架空です。
※チラシ・バナーはオープン時の版、LPはオープン後に通常の値段での営業が始まってからの版、という設定で作っています。
※写真は素材サイト（Unsplash）のものです（実際のご依頼では、お店の写真を使います）。

Concept

課題と、制作の意図

  • 課題髪質改善のサロンは数が多く、「ツヤ」「うるおい」など同じような言葉が並びがちで、違いが伝わりにくい
  • 誰に平日の夜や土日に通う、30〜40代の働く女性
  • 伝えること施術のあと、毎朝の支度がひとつ楽になること。初回の値段と予約の方法
  • コンセプト「乾かすだけで、朝がひとつ軽くなる。」。白と余白で静かに見せ、ページも販促物も同じ言葉と色でそろえる

Thinking

考えたこと

  1. 「髪がきれいになる」ではなく、「朝が変わる」と言う

    髪の仕上がりを言葉で競うより、働く人の毎日の困りごとに寄せた方が伝わると考えました。そこで、朝の支度がひとつ減ることを、ページのいちばん大きな言葉にしています。

  2. 色は、主役の写真から取る

    美容でよく使われるピンクや茶色から離れ、白と墨を基本にしました。差し色は、主役の写真に写るかすみ草の茎の緑だけで、値段の数字と予約ボタンにしか使っていません。

  3. 効果を言い切らない

    お客様の声・星の評価・ビフォーアフターは作っていません。効果の近くには「※仕上がりには個人差があります」、持ちの長さには「目安」と書き、根拠のない数字を出さないようにしました。

  4. 文章は、写真に合わせる

    素材写真の店内は、席の間に仕切りがなく、間隔も特別に広くはありません。そのため、プライバシーをうたう文章はやめて、「仕切りのない、ひらけた店内です」と写真どおりに書いています。

Design

LPで工夫したこと

スマホで見たときの画面です。

  • 最初の画面に、言葉と初回の値段

    写真を大きく見せたあと、言い切りの言葉・初回の値段・予約ボタンが続きます。ボタンや飾りを増やさず、余白で読ませる組み方です。

  • 髪質改善とは何かを、短く

    一般的なトリートメントとの違いを最初にひと言で説明し、そのあとに診断・補修・定着の3つの工程を並べました。診断の工程には、髪質診断カルテの記入欄を細い罫線で添えています。

  • 違いは、比較表で

    ケアの方法・配合・持ちの目安を、一般的なトリートメントと並べました。持ちの長さには「目安」と添えています。

  • メニューは所要時間まで

    3つのメニューに、初回の値段（税込）と所要時間を添えました。仕事のあとに通う人が、予定を立てやすいようにしています。

Promotion

販促物も、同じ言葉と色で

LPと同じ言葉・色で、お店が使う販促物をまとめて作りました。写真は5枚を使い分け、並べても単調にならないようにしています。
どれを見ても同じお店だとわかることを大切にしています。画像を押すと、大きく表示します。

オープン告知のチラシ

A4縦・片面／塗り足し3mmとトンボ付きのPDF

課題
オープン前のお店を、ポスティングや手配りで知ってもらう
意図
オープン日と、お店の静かな雰囲気を1枚で伝える。LPと同じ写真を紙面の上3分の2に大きく置き、言葉は髪の暗いところに白い縦書きで重ねました
工夫
オープン時のチラシは、まだ通常の値段で営業した実績がない時期のものなので、「通常○円→初回○円」の二重の表示はせず、オープン記念の値段と期限だけを載せました（バナーも同じです）。文字は紙の端から9mm以上内側、いちばん小さい文字も8pt以上です

LINEのリッチメニュー

2500×1686（6分割）と 2500×843（3分割）

課題
トーク画面の下のメニューは、スマホでは元の大きさの約15%に縮んで表示される
意図
いちばん押してほしい「初回のご予約」が、ひと目でわかるようにする
工夫
ボタン名はスマホで約15pxに見える大きさにしました。写真のマス（予約・店内）と白いマスで重さを変え、区切りの線はスマホで約1pxに見える細さです

予約サイトに載せる画像

店内・メイン・クーポン・ブログのサムネイルの4枚（うち2枚を掲載）

課題
予約サイトでは、近くのたくさんのサロンと並べて見比べられる
意図
並んだときにも、LPと同じ静かな雰囲気で「同じお店」とわかるようにする
工夫
クーポンは写真を外し、対象・所要時間・内容・ロングヘアの料金を髪質診断のカルテの罫線で整理しました。ブログのサムネイルは、LPのよくある質問から題材を取っています。サイトの名前やロゴは入れていません

Webバナー（伝え方の違う3案）

各案 1080×1080（SNS広告）と 1200×628（Web広告・アイキャッチ）

課題
広告は、どの言葉がいちばん反応されるかを、出してみるまで決めにくい
意図
実際の広告では複数の案を出して反応を比べることを前提に、「初回の値段」「髪の悩み」「朝の時間」と入口の違う3案を作りました
工夫
言葉だけでなく、構図も変えています。案1は髪の寄りの写真の下に値段を大きく、案2は写真を全面に、案3は文字を主役にして写真を小さく。写真も3案で別のものにしました。値段・期限・ロングヘアの追加料金・個人差の注意書きは、3案とも同じにそろえました

Instagram投稿

1080×1350・3枚

課題
フィードで流れていく中で、何のお店かを3枚で伝える
意図
1枚目で言葉、2枚目で違い、3枚目で施術の流れ、と順に知ってもらう
工夫
3枚の組み方を変えました（写真の上に縦書き／縦線1本で比べる表／カルテの罫線）。文章はLPのものをそのまま使い、言うことがずれないようにしています

Check

確認したこと

  • 画面幅と文字の大きさLPはスマホ・タブレット・パソコンで確認しました。チラシは8pt以上、リッチメニューはスマホで縮んだときの大きさで確認しています。
  • 表現のルール効果の言い切り・お客様の声・ビフォーアフターがないこと、持ちの長さに「目安」があること、オープン時の版のチラシとバナーに二重の値段の表示がないことを確認しました。
  • 媒体ごとに、載せる内容を決めてそろえる初回の値段（8,250円・税込）は、LPとすべての販促物で同じです。LPはオープン後の版なので、通常の値段を並べて載せ、期限は書いていません。チラシとバナーはオープン時の版なので、通常の値段は載せず、期限を「12月26日（土）まで」にそろえました。ロングヘアの追加料金は、LP・チラシ・バナー・クーポン画像で同じ2,200円です。
  • 架空の情報であること住所・駅・電話番号・URLは、実在の場所や番号を指さない架空の書き方にしています。各画像の隅にも「架空のサロンのサンプルです」と入れました。
