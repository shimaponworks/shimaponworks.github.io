クリニックの
看護師採用LP・求人バナー・チラシ

あさひ台内科クリニック（架空のクリニック・架空の依頼）

担当
キャッチコピー・構成・文章・デザイン・コーディング・写真選び、求人バナー3案（2サイズずつ）、院内掲示用の募集チラシ（A4・印刷用PDF）
使ったもの
HTML / CSS / JavaScript（バナーとチラシもHTML/CSSで組んで書き出し）

実際の募集の形をまねた想定の依頼「求人サイトに出しても、ブランクが不安で面接の前に辞退されてしまう」に答えた作例です。伝えたいことを「ブランクがあっても、日勤だけで戻れる」のひとつにしぼり、「手は、覚えている。気持ちが追いつくまで、となりで。」と、最初の1か月は先輩がとなりで採血・点滴を一緒に行うことを具体的に見せました。

雇用形態・勤務時間・休日・給与などの条件は省かずにすべて載せ、性別や年齢を限る言葉、根拠のない言い切りは使っていません。色は白と墨に「朝日の朱」を少しだけ。淡い朱の地を使う所や線の扱いをひとつのルールにして、LP・バナー・チラシをそろえています。

写真は素材サイト（Unsplash）のイメージです。給与などの条件はすべて架空の例です。

歯科医院の
定期健診の案内LP・バナー・チラシ

こもれび歯科（架空の歯科医院・架空の依頼）

担当
キャッチコピー・構成・文章・デザイン・コーディング・写真選びと加工、バナー3案（2サイズずつ）、院内とご近所に置くチラシ（A4・印刷用PDF）
使ったもの
HTML / CSS / JavaScript（バナーとチラシもHTML/CSSで組んで書き出し）

実際の募集の形をまねた想定の依頼「治療が終わると、定期健診に戻ってこない」に答えた作例です。行くと長く通うことになる、という不安を最初に消すことにして、「痛む前に、みがく。削る前に、守る。」と、健診の日は削らないこと・1回 約45分という事実を、LP・バナー・チラシのすべてに添えました。

体験談やビフォーアフター、「痛くない」「No.1」「最新」は使っていません。ホワイトニング（自由診療）は、限定解除で決められた項目（内容・回数・期間・費用・リスクと副作用ほか）を同じ大きさでそろえて書けるLPの中だけで案内し、チラシとバナーには載せていません。色はごく薄い桃の地にローズ。医院名の「こもれび」から、葉の影の写真を地に重ねています。

写真は素材サイト（Unsplash）のイメージです。スマホに映っている予約画面は、制作側で作った架空のものです。費用などの数字は、医院からいただく数字を入れる枠の形で示しています。

美容サロンの
LP・チラシ・バナー・SNS画像

hair salon「Lumio」（架空のサロン）

担当
構成・文章・デザイン・コーディング・写真選び、オープン告知のチラシ（A4・印刷用PDF）、Webバナー3案（2サイズずつ）、トーク画面の下に出すメニュー画像、予約サイトに載せる画像、Instagram投稿3枚
使ったもの
HTML / CSS / JavaScript（チラシや画像もHTML/CSSで組んで書き出し）

髪質改善トリートメントを、平日の夜や土日に通う働く女性に向けて「乾かすだけで、朝がひとつ軽くなる。」と言い切りました。白と余白を広くとり、色は主役の写真のかすみ草の茎の緑を、予約ボタンなど要所だけに使っています。作ったお客様の声やビフォーアフターは載せていません。

チラシ・バナー・メニュー画像・予約サイト用の画像・Instagramも、LPと同じ言葉・写真・色でそろえ、どれを見ても同じお店だとわかるようにしました。バナーは「初回の案内」「髪の悩み」「朝の時間」と伝え方を変えた3案で、実際の広告では複数の案を出して反応を比べられるようにしています。

写真は素材サイト（Unsplash）のものです。

勤怠管理サービスの
LP・広告バナー・展示会チラシ

勤怠管理サービス「Clocca」（架空のサービス）

担当
キャッチコピー・構成・文章・デザイン・コーディング・資料請求フォーム、資料ダウンロード広告のバナー3案（2サイズずつ）、ウェビナー告知バナー、展示会チラシ（A4両面・印刷用PDF）、ホワイトペーパーの表紙（A4縦）
使ったもの
HTML / CSS / JavaScript（バナー・チラシ・表紙もHTML/CSSで組んで書き出し）

「展示会で名刺は集まるのに商談にならない」「ページが他社と同じに見える」という想定の依頼に答えた作例です。中小企業の総務の方に向けて、月末の勤怠集計が「作る」作業から「確かめる」作業に変わることを、「月末の勤怠集計を、作るから、確かめるへ。」のひと言にしました。比べる相手は他社ではなく、Excel・タイムカードで管理している今です。

地は事務用紙のような薄い灰、文字とボタンはネイビー、深めの赤は「確認印」と「確かめる」の2か所だけ、というルールを、ページと4種類の販促物のすべてで同じにしています。展示会チラシは、表面を言葉と確認画面と費用の3つだけにし、機能は裏面へ、詳しい内容は資料へ送る形です。

写真は使っていません。根拠のない数字・導入事例・お客様の声は載せていません。会社名・展示会名・画面の中の名前と数字はすべて架空です。

コンタクトレンズの
楽天市場の商品ページ

SUMICLE 1DAY「1日使い捨てコンタクトレンズ」（架空のブランド・商品）

担当
ブランド名・構成・文章・デザイン、スマホ用の縦長画像10枚、商品画像3枚、楽天にそのまま貼れるHTMLと登録用の文章
使ったもの
HTML / CSS（画像の書き出し用）

毎月のレンズ代を下げたい方に向けて、「4箱なら1箱あたり1,190円（税込）」「両目1か月あたり2,380円」と、1か月にいくらかかるかがすぐ分かるように組みました。高度管理医療機器なので、見え方や目への良さには触れず、値段の数字と「眼科で処方された含水率とBCに合わせて選ぶ」ことだけを書き、使用上の注意と表示事項もページの中に入れています。1枚目の商品画像は楽天のガイドライン（文字は面積の20%以内・枠線なし）に合わせています。

写真（人物・商品の箱）は画像生成AIで作成したイメージです。ブランド・商品・会社・承認番号・値段はすべて架空です。

ふらっと入ったお客さまにも、何を頼めばいいかがすぐ伝わるように、1ページ1ジャンルにし、上の写真の料理を品書きの1品目にそろえて「一押し」の判を押しました。値段は比べやすい算用数字にして各列の下にそろえ、品名とは点線でつないでいます。お酒は「酒場」らしく12品にし、ソフトドリンクと合わせて二段に収めました。表紙は上を夜の色にして、和紙を切り抜いた三日月と店名を大きく置き、表紙だけで店の名前が伝わるようにしました。

写真は画像生成AIで作成したイメージです。

楽天市場の商品ページ

お歳暮やクリスマスの贈りものを探す方に向けて、キャッチ「果実を、ほおばるジュレ。」のとおり果肉の大きさが伝わるように、1枚目から果肉を大きく寄って見せ、4つの味も1枚ずつ寄りの写真で並べました。季節の用途とギフト対応は1枚にまとめています。楽天のスマホ用ページはCSSが使えないため、縦長の画像を分けて並べる形にし、1枚目の商品画像は、一覧で何の商品か分かるように商品名を入れ、ガイドライン（文字は面積の20%以内・枠線なし）に合わせています。

写真は画像生成AIで作成したイメージです。

ポスター（A2）

「第12回 みなと循環器セミナー」（架空の会）

担当
構成・デザイン・印刷用データ（CMYK・塗り足し3mm・トンボ付きPDF、文字をアウトライン化した .ai）

掲示の前を通りすぎる医師・メディカルスタッフにも「何の会が・いつ」が伝わるように、写真を使わず、会の名前・テーマ・日付を大きな文字で組みました。近づけば時刻・プログラム・参加費・申込方法まで読めるよう、下の段に文字の大きさを分けてまとめています。飾りは紙面を横切る心電図の線1本だけにし、赤はその1拍にだけ使っています。

写真は使っていません。会の名前・会場・人名・QRコードなど、紙面の内容はすべて架空のダミーです。
